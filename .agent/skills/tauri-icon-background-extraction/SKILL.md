# Tauri/PWA Icon Extraction using Sharp

このスキルは、TauriやPWAのアイコン生成において、「四角い背景ごと縮小されてしまい、余計な枠や黒い隙間ができる現象」を解決するためのスクリプト実装アプローチを提供します。

## 症状や背景
- ユーザーが作成したアプリアイコン（通常は角丸の四角形や完全な正方形、背景がグラデーションなどで塗りつぶされている）をそのままPWAやTauriのビルダーに渡すと、プラットフォームによっては全体が小さく縮小され、周りに不格好な枠（黒色や透明）ができてしまうことがあります。
- 新しいWindowsやmacOSのアプリアイコンは、完全な四角形ではなく「ロゴそのものの形（フリーフォーム）」や「枠なし」のデザインが好まれるケースがあります。

## 具体的な解決策（Node.js / Sharp を使用した透過処理）

Sharpライブラリを用いて、以下のステップで背景色を透過（アルファチャンネル操作）させ、ロゴの形だけを切り出します。

### 1. 色の距離（Color Distance）による境界の抽出
画像のトップレフト（背景）の色を取得し、すべてのピクセルとのユークリッド距離を計算します。
距離が近い（背景色と同系色）場合は完全に透明（alpha=0）にし、閾値の境界ではグラデーション（alphaを滑らかに補間）させることで、光るエフェクトやアンチエイリアスを自然に残すことができます。

### 2. コンテンツのバウンディングボックスの計算
透過させた後のピクセルデータを走査し、alpha値が一定以上あるピクセルの最小・最大のX/Y座標を求めます。これにより、ロゴの存在する最小の矩形領域がわかります。

### 3. PaddingとOffset（重心調整）による再配置
抽出した矩形画像を、そのまま中心に置くだけでは「視覚的な重心」が偏る場合があります（例：右下に伸びているロゴなど）。
そのため、余白サイズ（Padding）と同時に、視覚的な重さに合わせて上下左右に何％ずらすか（Offset）を定義し、`.composite()` で新しい透明なキャンバスに配置します。

```javascript
// スクリプトのハイライト例
const pad = Math.round(Math.max(cropW, cropH) * 0.02); // 2%の余白で大きく表示
const shiftX = Math.round(cropW * 0.03);               // 3% 右へずらす
const shiftY = Math.round(cropH * 0.12);               // 12% 下へずらして視覚的重心を中心に

await sharp({
  create: {
    width: canvasW,
    height: canvasH,
    channels: 4,
    background: { r: 0, g: 0, b: 0, alpha: 0 }
  }
})
  .composite([{ input: croppedBuffer, top: pad + shiftY, left: pad + shiftX }])
  .png()
  .toBuffer()
  .then(extendedBuffer => {
    // 最後に任意の各プラットフォーム用解像度にリサイズ
    sharp(extendedBuffer).resize(1024, 1024).toFile('icon.png');
  });
```

## 注意事項や制約
- Sharpの `image.raw()` を用いる場合、入力画像が3チャンネル（RGB）か4チャンネル（RGBA）かを必ず確認し、RGBAバッファに変換してからアルファ値の操作を行う必要があります。
- 透過や輝度の判定ロジックは、対象のアイコンの色彩に大きく依存します。白背景の処理であれば明るさ(L)を使う、特定色であればHSVなどで判定するなど調整が必要です。
